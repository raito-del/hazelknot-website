# হ্যাজেলনট · হাতে-বোনা ক্রেশেট শপ ওয়েবসাইট

এটা একটা স্ট্যাটিক ওয়েবসাইট। কোনো সার্ভার বা ডেটাবেস লাগে না, তাই GitHub Pages-এ সরাসরি চলবে।

## ফোল্ডার কাঠামো

```
hazelknot-website/
├── index.html            মূল পেজ (HTML কাঠামো)
├── css/
│   └── style.css         সব স্টাইল, রং, ফন্ট, অ্যানিমেশন
├── js/
│   └── script.js         প্রোডাক্ট, কার্ট, অর্ডার, অ্যানিমেশন
├── config/
│   └── settings.js       ★ আপনার মেসেঞ্জার পেজের লিংক এখানে বসান
└── README.md             এই ফাইল
```

## ধাপ ১: নিজের তথ্য বসান

**১. মেসেঞ্জার ও ফেসবুক পেজের লিংক**
`config/settings.js` ফাইল খুলুন এবং `messengerPage` লাইনে আপনার পেজের ইউজারনেম লিখুন।
উদাহরণ: `facebook.com/hazelknot` হলে `messengerPage: "hazelknot"`।
এই একটা জায়গা বদলালেই পুরো ওয়েবসাইটে সব মেসেঞ্জার বাটন ঠিক পেজে যাবে।

**২. প্রোডাক্ট ও দাম**
`js/script.js` ফাইলে `PRODUCTS` লেখা অংশটা খুঁজুন। সেখানে প্রতিটা প্রোডাক্টের নাম, দাম (`price`), রং ও সাইজের অপশন (`options`) বদলাতে পারবেন।

**৩. রং বদলানো**
`css/style.css` ফাইলের শুরুতে `:root` অংশে রংগুলো আছে। আর `data-palette` অংশে তিনটা রঙের প্যালেট (Berry, Mint, Sunset)।

## ধাপ ২: GitHub-এ আপলোড করুন

1. GitHub-এ একটা নতুন রিপোজিটরি বানান, যেমন `hazelknot-website`। Public রাখুন।
2. জিপ ফাইলটা আনজিপ করুন।
3. রিপোজিটরির পেজে **Add file → Upload files** চাপুন।
4. আনজিপ করা ফাইল ও ফোল্ডারগুলো (`index.html`, `css`, `js`, `config`, `README.md`) টেনে ছাড়ুন। নিজের ফোল্ডারের ভেতরের জিনিস আপলোড করুন, জিপ নিজে নয়।
5. **Commit changes** চাপুন।

## ধাপ ৩: ওয়েবসাইট চালু করুন (GitHub Pages)

1. রিপোজিটরিতে **Settings → Pages** খুলুন।
2. **Source** থেকে **Deploy from a branch** বেছে নিন।
3. **Branch** থেকে `main` এবং ফোল্ডার `/ (root)` বেছে **Save** চাপুন।
4. কয়েক মিনিট পর সাইট এখানে চালু হবে:
   `https://আপনার-ইউজারনেম.github.io/hazelknot-website/`

## অর্ডার কীভাবে কাজ করে

ক্রেতা প্রোডাক্ট ও তথ্য দিয়ে **"Send order on Messenger"** বাটনে চাপলে:
- পুরো অর্ডারের বিবরণ কপি হয়ে যায়।
- আপনার ফেসবুক পেজের মেসেঞ্জার চ্যাট খুলে যায়।
- ক্রেতা শুধু চ্যাটে পেস্ট করে পাঠাবেন।

**জানা কথা:** মেসেঞ্জারের লিংকে লেখা আগে থেকে বসানো যায় না। তাই পেস্টের ধাপটা রাখতে হয়।

## কোডের ফাইল বদলালে

ফাইল বদলে GitHub-এ আবার আপলোড (বা **Edit** করে Commit) করলে এক-দুই মিনিটের মধ্যে ওয়েবসাইটে বদল দেখা যাবে।


## ছবি ও প্রোডাক্ট যোগ করা (নতুন সিস্টেম)

প্রতিটা প্রোডাক্টের নিজস্ব ফাইল আছে, তাই এক জায়গায় হাত দিলে অন্যটা নষ্ট হয় না।

- **`products/`**: প্রতিটা প্রোডাক্টের আলাদা `.js` ফাইল। এখানে নাম, দাম, ছোট লেখা, প্রজেক্ট ডিটেইল ও রং/সাইজের অপশন থাকে।
- **`images/products/`**: প্রোডাক্টের ছবি। ছবির নাম হবে প্রোডাক্টের `id`-এর সাথে মিলিয়ে, যেমন `cat-hug.jpg`।

**ছবি বদলাতে:** ছবিটা `images/products/` ফোল্ডারে রাখুন, নাম দিন `id.jpg`। ব্যস।

**নতুন প্রোডাক্ট যোগ করতে:** `products/_নতুন-প্রোডাক্ট-যোগ-করার-নিয়ম.txt` ফাইলের ধাপগুলো দেখুন।

**দাম বদলাতে:** সংশ্লিষ্ট `products/নাম.js` ফাইলে `price` লাইনে সংখ্যা বদলান।
